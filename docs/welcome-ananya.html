What this is

Horizon (product code name LearnPool) is AI-powered classroom Q&A. During a live class, students ask questions and get answers grounded only in that course's own materials — lecture PDFs, textbooks — never the open internet, always cited back to the source page.

The twist: it's not a private chatbot. Every question becomes a shared thread the rest of the class can see, vote on, comment on, and build on ("fork"). Students see how their classmates are learning, and whether the AI's answers actually held up — a green bar means the class agreed, a red one means someone caught a mistake. Teaching assistants get a dashboard rolling all of it up across the whole class.

What to look at inside Comedy 101

Ask a question Lectures → open a session

Open the most recent lecture and ask something about the course material in the chat box. Watch the answer stream in with a citation chip pointing to the exact page it came from — click the citation to see the source text inline.

The class feed same session → Report

This is the core social layer. Scroll through classmates' questions and answers. Look for: thumbs up/down on each thread, a fork badge where one student built on another's question, and comment threads underneath. This view is what makes Horizon feel different from a private AI chat — it's designed to be browsed, not just used.

Answer Quality Breakdown Report → scroll down

A diverging green/red bar per question showing classmate consensus — green means the class confirmed the answer, red means someone flagged it as wrong or oversimplified, with their comment attached. This is the single most important visualization in the product — it's the trust mechanism.

Material Coverage Report → citation map card

A per-page bar chart of which pages of the course PDF get cited most, ordered by page number. Shows which parts of the material the class is actually engaging with.

Category chart Report → top of page

Click a bar to filter the whole feed to just that category (Doubts / Homework / Exam Prep / Summaries) — a quick way to see what kind of help the class is asking for.

Classmates course page → People

The class roster — who's enrolled, who's the teaching assistant. Simple, but it's part of making the class feel like a real room instead of a solo tool.

Heads up — this is a shared demo account seeded with realistic (but fake) student activity — about 30 classmates, 100+ questions, votes, comments, and a couple of forks — so everything should feel populated rather than empty. Don't worry about breaking anything; ask away, vote on things, leave a comment. It's all disposable test data.
