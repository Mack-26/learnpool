If x + 1/x = 5, what is x² + 1/x²? I keep trying to solve for x first and running out of time.

Horizon Answered from Quant Review — Algebra · 2 passages 16 found this helpful

You don't need x at all. Square the expression you were given — the cross terms collapse into a constant: [1]

(x + 1/x)² = x² + 2·(x · 1/x) + 1/x² = x² + 2 + 1/x²
25 = x² + 2 + 1/x² → x² + 1/x² = 23

Your notes call this the sum-and-square pattern: when you're handed a sum and asked for squares, square the sum first. Problem Set 4 Q2 is the same shape with a 7 instead of a 5. [2]
